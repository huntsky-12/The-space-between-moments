# Insanity Is a Bane.

Pages 1–3 are one continuous native-scroll canvas.

Trackpad / mouse wheel:
- Works immediately when the site opens — no click or focus required.
- Swipe/scroll UP -> next scene.
- Swipe/scroll DOWN -> previous scene.
- CSS scroll-snap locks scenes to one viewport, with scroll-snap-stop to
  prevent normal trackpad scrolling from casually skipping scenes.

Touch:
- Native swipe/scroll works.

Keyboard:
- Arrow Up/Down and Page Up/Down.

Navigation controls:
- ENTER and menu links use smooth scrollIntoView.

Page 1 ENTER has been moved lower again so its visible label/arrow aligns
with Page 2 THE WRITINGS.
